衰减使用 MoveTowards(opiateAmount, 0, rate * deltaTime) 叠加多个 if 块执行，高浓度时所有匹配的分段都会触发。

2.2 opiateTolerance 耐受动态

opiateTolerance < opiateAmount:
  → 以 0.08/s 追赶 opiateAmount (上升)

opiateTolerance > opiateAmount:
  → 以 0.04/s 下降 (下降速度 = 上升的一半)

额外调节:
  opiateReception > 45  → 追赶 +0.022/s (高过量加速耐受)
  opiateReception < -30 → 下降 +0.025/s (严重戒断加速脱敏)

opiateTolerance 最低值: 0 (clamp)

2.3 actualOpiateReception 平滑

opiateReception = opiateAmount - opiateTolerance    (每帧瞬时值)
actualOpiateReception → opiateReception              (MoveTowards, 5/s)

2.4 拮抗剂 antagonistAmount

antagonistAmount 每帧自减 deltaTime (约 1/s 衰减)
antagonistAmount > 0 → opiateAmount 额外衰减 8/s (与上述分段叠加)

2.5 组件自毁

关键含义：Painkillers 组件仅在体内有阿片类物质或有耐受时存在。无药物无耐受时组件完全移除。拮抗剂没有预防作用——如果从未使用阿片，使用纳洛酮/纳曲酮无法提前降低随后使用的鸦片量
