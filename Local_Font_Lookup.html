2 手动获取并导入

在合适的页面用 Chromium 内核的浏览器（如 Chrome、Edge）控制台运行以下代码：

// 在浏览器控制台(F12)中粘贴并回车运行 async function getLocalFonts() { try { const fonts = await window.queryLocalFonts(); const fontDetails = fonts.map(f => ({ family: f.family, fullName: f.fullName, style: f.style, weight: f.weight, postscriptName: f.postscriptName })); // 下载为JSON文件 const blob = new Blob([JSON.stringify(fontDetails, null, 2)], {type: 'application/json'}); const url = URL.createObjectURL(blob); const a = document.createElement('a'); a.href = url; a.download = '本机字体列表.json'; a.click(); URL.revokeObjectURL(url); return fontDetails; } catch (err) { console.error('需要用户授权访问字体，或浏览器不支持。', err); } } await getLocalFonts();

注意

  • 运行后会弹出授权请求，请点击"允许"
  • 需要 Chromium 103+ 版本支持 queryLocalFonts() API
  • 下载的JSON文件可直接导入本页面
