09 / READING THE THEME

从映射出发，
而不是替颜色编排故事。

01

语义要结合上下文

玫红既用于关键字，也用于错误与删除；青蓝既用于类型，也用于信息提示。源文件能证明这些映射，但不能证明某套“色彩心理学”或唯一的视觉权重排序。

02

结构色也有例外

通用标点使用 #8b888f，但字符串边界、模板插值与语言专用标点有覆盖规则。不能把“所有标点都是灰色”当作硬性规则。

03

Diff 同时使用前景与背景

新增和删除分别使用绿与玫红，且存在 #7bd88f19 与 #fc618d19 行背景。因此它并不只靠前景色表达变化。

04

静态定义不是最终像素

当前主题 JSON 没有显式 semanticTokenColors、semanticHighlighting 或 include 字段。语言服务器、语法扩展与用户覆盖仍可能改变编辑器中的实际呈现。
