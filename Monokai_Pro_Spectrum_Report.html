🎨 色彩层级结构

前景色层级（视觉重量从重到轻）

  1. #fc618d (珊瑚红) — 最高权重：语言关键字、运算符、HTML/XML 标签、存储类型、错误
  2. #fce566 (琥珀黄) — 高权重：字符串、标题、diff 修改、搜索匹配
  3. #5ad4e6 (天蓝) — 中-高权重：类型、类名、命名空间、Rust 关键字、CSS 选择器
  4. #7bd88f (薄荷绿) — 中权重：函数名、支持函数、类引用、diff 新增、链接
  5. #fd9353 (暖橙) — 中权重：参数、CSS 标识符、占位符、符号
  6. #f7f1ff (淡紫白) — 基础文本：源代码主体、JSON 键、变量、对象成员
  7. #948ae3 (淡紫) — 低权重：常量、数字、正则表达式、行号
  8. #bab6c0 (银灰) — 实体名（注释内）、标点定义、伪类
  9. #69676c (冷灰) — 注释、文档字符串、最弱对比度

结构性色彩

#8b888f (中灰) 是唯一的"结构色"：

  • 所有标点符号（括号、逗号、分号）
  • 元 braces（meta.brace.*）
  • Jinja2 分隔符（entity.other.jinja2.delimiter）
  • Git 元信息（author、date、commit hash）
  • Shell 变量分隔符（keyword.operator.type.annotation）

这确保了代码结构骨架始终以"低存在感"方式呈现，不会与语义着色冲突。

🔍 值得注意的模式

  • Rust 语言的重度定制 — 存在大量以 rust 为后缀的作用域（如 keyword.other.rust），且同一个作用域可能因"调整蓝至红"而有两次不同颜色定义。
  • CSS/SCSS/LESS 统一使用橙色 (#fd9353) 作为变量引用的颜色，形成视觉一致性。
  • Python 自参数特殊处理 — self 和 cls 使用 variable.parameter.function.language.special 专门作用域，着色为 银灰 #bab6c0 + 斜体，与普通参数（橙色）区分。
  • Diff 语义完全由前景色驱动 — 新增用绿色 (#7bd88f)、删除用珊瑚红 (#fc618d)、修改用琥珀 (#fce566)、头部用黄色，无需背景色变化即可传达语义。
  • Region 标记系统 — 8 种区域色（蓝、绿、橙、粉红、紫、红、白、黄）均使用自身颜色 + 35% 透明度作为背景，同时以不透明前景色显示文字标签。
  • UI 背景使用 3 种灰度阶 — #131313 (主背景) → #191919 (侧栏/活动栏) → #222222 (编辑器区域) → #363537 (面板/下拉)，形成精确的层级对比。
  • Terminal ANSI 色完全复用语法色板 — 终端的 16 色 ANSI 配色直接对应了语法高亮颜色，确保终端代码与编辑器内一致。
