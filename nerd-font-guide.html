NERD FONT × WINDOWS / WSL

给终端换一副好字体。

一个常驻 WSL，一个常驻 Windows。字体可以用同一款，提示符按各自的 Shell 配。

Nerd Fonts 是一组补入开发者图标的字体，以及相应的补字工具。它让终端主题能显示文件夹、Git 分支等符号。字体决定字和图标怎么画，主题决定哪些信息出现、用什么颜色。项目说明 ↗

带 NF，不等于带中文。很多字体里的中文其实来自系统回退字体；想让中英文风格统一、宽度稳定，直接选内含中文字形的版本。

Windows Terminal

终端窗口：选字体、背景和配色。

PowerShell / Bash / Zsh

Shell：执行你输入的命令。

Oh My Posh

提示符引擎：显示路径、Git 等状态。

私心推荐 · 默认就选它

Maple Mono NF CN

真心建议先装这款，再考虑要不要折腾别的。圆角字形有辨识度，中文、英文与 Nerd 图标一次配齐；中文占两个英文字符宽，中英混排和文本表格很舒服。它还支持编程连字，简体、繁体中文与日文都有覆盖。

认准后缀：NF = 图标，CN = 中文。中文字符间距比较宽松；喜欢紧凑排版可以试试下面的更纱。连字只是显示效果，不会改掉代码字符。

03 /装 Oh My Posh，到底有啥用？

它把每次输入命令前的提示符，变成一条随目录和命令结果变化的状态栏。你不用每次都主动查询，就能看到常用上下文。

  • 少认错仓库和分支：显示当前路径、Git 分支、未提交改动及领先 / 落后状态。Git 模块
  • 知道刚才跑得怎么样：按主题显示上一条命令的退出状态和耗时，失败时更醒目。退出状态 · 耗时
  • 两边看起来、用起来更一致：PowerShell、Bash 和 Zsh 可以读取同一种主题配置；具体显示哪些信息，由主题和本地工具决定。支持的 Shell

经常切项目、分支和环境，值得装。偶尔敲一条命令，则按喜好选择。它不负责命令补全，也不会让命令本身跑得更快；复杂主题反而可能增加提示符等待时间。Nerd Font 提供图标字形，Oh My Posh 负责把信息排出来。

你主要在哪里敲命令照哪条路线做
朋友：Windows PowerShell 7Windows 安装 → 写入 $PROFILE
你：WSL 的 Bash / ZshWSL 安装 Linux 版 → 写入 .bashrc / .zshrc

两边都用就各装一份。仅在 Windows 安装，并不会自动改变 WSL 的提示符；WSL 路线不要求先安装 Windows 版 PowerShell 或 Oh My Posh。

04 /共同准备：先选好字体

字体装在 Windows，两个环境都能用

打开上面的 Releases，展开 Assets，下载名称含 MapleMono-NF-CN 的字体压缩包（如 MapleMono-NF-CN.zip）。解压后选中 TTF 文件，右键“安装”；建议连同粗体、斜体一起装。

重启 Windows Terminal → 设置 → 配置文件 → 对应环境 → 外观 → 字体，选择 Maple Mono NF CN 并保存。分别为 PowerShell 和 WSL 的 Ubuntu / Debian 配置文件选好字体；也可在“默认值”里统一设置，并检查各配置文件有无覆盖。

已经用 Scoop？也可运行 scoop bucket add nerd-fonts，再运行 scoop install Maple-Mono-NF-CN。无需专门为这一步安装 Scoop。

通过 Windows Terminal 使用 WSL 时，文字由 Windows 端绘制，通常无需在 WSL 内重复安装字体。官方字体说明。WSLg 的 Linux GUI 终端是另一种情况，需要让 Linux 应用也能找到该字体。

05 /朋友的路线：Windows + PowerShell 7

适用于 Windows 10 / 11，使用 Windows Terminal。普通用户窗口即可；已经装好的软件跳过对应命令。

1. 安装 PowerShell 7 与 Oh My Posh

在现有 PowerShell 中执行
winget install --id Microsoft.PowerShell --exact --source winget
winget install --id JanDeDobbeleer.OhMyPosh --exact --source winget

随后完全关闭并重新打开 Windows Terminal，从下拉菜单进入 PowerShell（7），不是 Windows PowerShell（5.1）。Terminal 未安装可先从 Microsoft Store 安装。

后续命令都在 PowerShell 7 里执行。两代 PowerShell 的 $PROFILE 路径不同，别在旧窗口配置完后去新窗口找效果。

2. 保存一个主题到本地

先用官方示例主题 jandedobbeleer，包含路径、Git 等信息。这一步需要联网；保存后，日常启动从本地读取配置。

PowerShell 7 · 执行
oh-my-posh config export --config jandedobbeleer --output "$HOME/.mytheme.omp.json"

若这个文件已存在，先备份或改用另一文件名，并同步修改下一步的路径。

3. 写入启动配置

创建缺失的配置文件，然后用记事本打开；已有内容会保留。

PowerShell 7 · 执行
if (!(Test-Path -LiteralPath $PROFILE)) {
    New-Item -ItemType File -Path $PROFILE -Force | Out-Null
}
notepad $PROFILE

在记事本里，将下面这一行加到文件末尾并保存。如果已有 Oh My Posh 初始化行，替换那一行即可。

粘贴到 $PROFILE 文件
oh-my-posh init pwsh --config "$HOME/.mytheme.omp.json" | Invoke-Expression

回到 PowerShell 执行下面一行，立即生效。以后每次打开都会自动加载。

PowerShell 7 · 执行
. $PROFILE

想换风格？去 主题画廊 挑一个，把第 2 步的主题名换掉，重新导出后再运行 . $PROFILE。终端背景和整体配色则在 Windows Terminal 的“外观”里调整。

依据：PowerShell 安装 · Oh My Posh 安装 · 启动配置 · 本地主题 · Terminal 字体设置

06 /你的路线：WSL + Bash / Zsh

以下命令在 WSL 内运行。以 Ubuntu / Debian 的 Bash 为主；用 Zsh 的安装步骤相同，只改最后的启动配置。这里安装 Linux 原生版，不借用 Windows 的 oh-my-posh.exe。

1. 在 WSL 安装 Oh My Posh

先装依赖，再用官方脚本安装到当前 Linux 用户的 ~/.local/bin。只有安装依赖需要 sudo。

WSL · Ubuntu / Debian · 执行
sudo apt update
sudo apt install -y curl unzip ca-certificates coreutils
mkdir -p "$HOME/.local/bin"
curl -fsSL https://ohmyposh.dev/install.sh | bash -s -- -d "$HOME/.local/bin"
export PATH="$HOME/.local/bin:$PATH"
oh-my-posh --version

其他发行版用自己的包管理器安装同名依赖。已安装 Linux 版时，直接运行 command -v oh-my-posh 和 oh-my-posh --version 检查，正常就跳过重装。

2. 下载和 Windows 相同的主题

WSL · 执行（需要联网）
oh-my-posh config export --config jandedobbeleer --output "$HOME/.mytheme.omp.json"

Windows 的 $HOME 与 WSL 的 $HOME 是不同目录；这里在 Linux 家目录保存自己的配置。已有同名文件时，先备份或换名。

3. 让每个新终端自动加载

Bash：编辑 ~/.bashrc，在末尾加入以下两行。如果已有其他提示符主题初始化，替换它，避免相互覆盖。

粘贴到 ~/.bashrc · Bash
export PATH="$HOME/.local/bin:$PATH"
eval "$(oh-my-posh init bash --config "$HOME/.mytheme.omp.json")"

保存后在当前 WSL 窗口运行：

WSL · Bash · 执行
source ~/.bashrc
我在 WSL 用 Zsh，怎么改？

把下面两行放到 ~/.zshrc 末尾（在 Oh My Zsh 等框架加载之后），不要写进 ~/.bashrc；保存后运行 source ~/.zshrc。

粘贴到 ~/.zshrc · Zsh
export PATH="$HOME/.local/bin:$PATH"
eval "$(oh-my-posh init zsh --config "$HOME/.mytheme.omp.json")"

拿不准当前 Shell？运行 oh-my-posh get shell 再选对应配置。

想同步两边风格：把同一份 .omp.json 复制到两边家目录，或用 Git 管理；分别保留 init pwsh / init bash / init zsh。也能通过 /mnt/c/Users/你的Windows用户名/... 引用 Windows 那份配置，但本地副本更方便独立使用。

若在 WSL 内运行的其实是 pwsh，安装仍按 Linux 路线，启动配置则写在该 Linux PowerShell 的 $PROFILE 中，使用 init pwsh。

依据：Linux 安装 · 各 Shell 初始化 · 主题配置与 WSL 共用配置

07 /中文 Nerd Font，精挑这几款

以下是自带中文字形 + Nerd 图标的选择。Maple 的几个版本属于同一家族，不必全部安装。

字体 / 版本适合谁
Maple Mono NF CN首选 · 简繁中文 / 连字想一次解决中文、图标与编程字体。圆角风格，中英文宽度 2:1。
Maple Mono Normal NF CN同家族 · 常规字形喜欢 Maple，但更习惯传统的英文字形；保留中文和图标。
Maple Mono NL NF CN同家族 · 无连字希望 !=、=> 等符号逐个显示。下载包名认准 MapleMonoNL-NF-CN。
Sarasa Term SC Nerd简体中文 · 更纱终端版偏爱紧凑、朴素的代码排版。中英文 2:1，图标尺寸针对终端调整。

普通的 JetBrains Mono Nerd Font、Meslo Nerd Font 并不因此自带完整中文字库；中文常靠系统字体回退。更纱原版也不等于 Nerd 版，下载时看清项目和后缀。

选择困难？就选第一行。Maple Mono NF CN，值得先用上几天。

08 /卡住时，只看这几条

图标是方框，或字体没有变化

先确认下载的是 NF CN 版，再检查当前 PowerShell 或 WSL 配置文件的字体设置，重启整个终端。VS Code 的集成终端需要单独设置 terminal.integrated.fontFamily 为 Maple Mono NF CN。

提示找不到 oh-my-posh

Windows：完整退出并重开 Windows Terminal，再运行 oh-my-posh --version。WSL：运行 command -v oh-my-posh，检查 Linux 版是否装好、~/.local/bin 是否在 PATH 中，以及 PATH 设置是否写在初始化行之前。

Windows 报“禁止运行脚本”

在你自己的电脑上，可为当前用户设置 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned，再执行 . $PROFILE。它允许本地脚本运行，对下载的脚本要求签名。公司或学校设备若由组策略管理，应遵循管理员设置。执行策略说明

PowerShell 重开后没主题，或想恢复原样

在实际使用的 PowerShell 中输入 $PROFILE，检查是否编辑了那个文件，以及窗口是否使用了 -NoProfile。恢复默认提示符：删除或注释初始化行，重新打开窗口；字体仍可保留。Git 信息通常只在 Git 仓库内出现。

WSL 重开后没主题，或想恢复原样

确认正在用 Bash 还是 Zsh，并检查相应的 ~/.bashrc 或 ~/.zshrc。想恢复默认提示符，移除 Oh My Posh 的 eval 初始化行，再新开终端；如果原先有别的主题，恢复其初始化设置。

WSL 在大仓库里，按回车后提示符很慢

Git 状态查询可能增加延迟。优先试用更简单的主题，减少不需要的 Git 状态字段。主要通过 Linux 工具工作的仓库，通常放在 WSL 的 ~/Projects 下更合适；位于 /mnt/c、/mnt/d 等 Windows 挂载盘时，跨文件系统访问可能更慢。微软的文件存放建议
